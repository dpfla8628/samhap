## Q1. 일주(日柱): JDN → 60갑자 공식, 기준일 검증, 자시(子時) 경계 관행

### Takeaway
일주 인덱스는 `idx = (JDN + 49) mod 60` (0 = 甲子, 천간 = idx mod 10, 지지 = idx mod 12)이며, 서로 독립인 4개 출처의 갑자 기준일(1912-02-18 甲子, 1949-10-01 甲子, 2000-01-01 戊午, 1992-10-24 癸酉 등)과 모두 일치한다. 한국 주류 관행은 "일주 날짜 경계 = 시계 자정 00:00"이고, 23시 이후를 다음 날로 보는 야자시(夜子時) 방식은 옵션으로만 제공된다.

### Cited Findings

**갑자 기준일 (서로 독립인 출처)**
- 중국어 위키백과 干支纪日: "1912年2月18日(农历壬子年正月初一日)"과 "1949年10月1日(农历己丑年八月初十日)"이 모두 甲子日. 그레고리력용 공식도 수록: `gz = 44C + ⌊C/4⌋ + 5y + ⌊y/4⌋ + 30(M+1) + ⌊3(M+1)/5⌋ + d + 7` (C=세기, y=연도 끝 두자리, 1·2월은 전년도 13·14월, 결과 mod 60, 0→60) — [zh.wikipedia 干支纪日](https://zh.wikipedia.org/wiki/干支纪日)
- 天气网 万年历(老黄历) 2000년 표: "2000年1月1日 星期六 … 干支:己卯年 丙子月 戊午日", 2000-01-02 己未日, 2000-01-13 庚午日 — [wannianli.tianqi.com 2000](https://wannianli.tianqi.com/laohuangli/2000nachu.html)
- 51CTO 블로그 예제: 1998-03-15 = 辛酉 — [blog.51cto.com](https://blog.51cto.com/u_15127603/4143566)
- yhj1024/manseryeok(KASI 데이터로 전 구간 검증했다고 명시) README 예제: 1992-10-24 → 계유일, 2024-03-10 → 계유일 — [github.com/yhj1024/manseryeok](https://github.com/yhj1024/manseryeok)

### Inferences
- 구현 권장: 일주는 **시계(KST, 서머타임 제거 후) 자정 00:00**을 경계로 하되, "야자시(23:00 이후 익일)" 옵션을 사용자 선택으로 제공. 30분 보정을 적용하는 경우 자시 시작은 시계 23:30이 되므로 야자시 옵션의 경계도 23:30이 됨(보정 후 시각 기준으로 23:00).
- `(JDN+49) mod 60`은 1912·1949·2000·1992·2024년 앵커 모두와 맞으므로 1900~2100 전 구간에서 신뢰 가능(60일 주기는 역법 개정과 무관하게 연속).
- 검색 스니펫에만 나온 hjsh200219/fortuneteller 저장소의 "1900-01-01 = 丙子, 2000-01-01 = 庚申, 2024-03-04 = 己巳"는 위 모든 앵커와 정확히 +2일 어긋남 → 해당 저장소 값은 오류로 추정(원 파일은 403/404로 직접 확인 불가).

### Gaps
- 포스텔러·점신 등 상용 앱의 **기본값**(야자시 ON/OFF, 30분 보정 ON/OFF)은 공식 문서에서 확인하지 못함. App Store 설명은 옵션 존재만 확인.
- 天气网 1987년 월별표는 자체 모순(7/13을 월력표는 辛亥, 하단 "今日黄历"는 癸亥로 표기)이 있어 1987년 일주의 외부 검증 자료로 쓰지 못함. 공식 계산값(癸亥)은 하단 박스와 일치.

## Q2. 년주(年柱): 입춘 경계와 공식

### Takeaway
년간 = (year − 4) mod 10 (甲=0), 년지 = (year − 4) mod 12 (子=0). 단 "year"는 달력 연도가 아니라 **입춘 절입 순간** 기준의 사주 연도이며, 입춘 순간 이전 출생은 전년 간지를 쓴다.

### Cited Findings
- 중국어 위키 干支: "將西元後年分減3，再除以10，所得餘數即為第幾干（餘0則視為第10干）" (甲=1 기준; 지지는 12로). 예 1995 → 乙亥, 1861 → 辛酉 — [zh.wikipedia 干支](https://zh.wikipedia.org/wiki/干支). (0 기반 인덱스로 바꾸면 (year−4) mod 10/12와 동일.)
- 명리 카페 자료(연주정립법): "年의 구분(경계)을 정월초하루로 하지 않고 입춘을 기준으로 정한다" — [m.cafe.daum.net/gildosa](https://m.cafe.daum.net/gildosa/D5Zt/126)
- datedb 월건 해설: "음력 1일이 아니라 24절기의 절입(節入)으로 달의 경계를 정합니다." — [datedb.net](https://datedb.net/calendar/wolgeon/2017/)
- manseryeok 라이브러리: "년주: determined by the 입춘 (Lichun) instant, not by the calendar year" — [github.com/yhj1024/manseryeok](https://github.com/yhj1024/manseryeok)
- 天气网 2000-01-01 간지 "己卯年 丙子月 戊午日": 2000년 1월 1일은 입춘 전이므로 1999년 기묘(己卯) 사용 — [wannianli.tianqi.com](https://wannianli.tianqi.com/laohuangli/2000nachu.html)

### Inferences
- 구현: `sajuYear = (t_KST < 입춘(year) instant) ? year − 1 : year`; `yg = ((sajuYear−4) % 10 + 10) % 10`, `yz = ((sajuYear−4) % 12 + 12) % 12`.
- 검증 실행: 2025-02-03 22:30 → 甲辰年, 23:30 → 乙巳年 (입춘 2025-02-03 23:10 KST, 아래 Q4 출처) — 경계 10분 차이로 연주가 바뀌므로 절기 시각 정밀도가 중요.

### Gaps
- 없음 (공식 자체는 보편적).

## Q3. 월주(月柱): 12절(節) → 월지 표, 월간(오호둔/연두법)

### Takeaway
월지는 12개 절(입춘→寅 … 소한→丑)의 절입 순간으로 바뀌고, 월간은 오호둔(五虎遁): 甲己년 丙寅월, 乙庚년 戊寅월, 丙辛년 庚寅월, 丁壬년 壬寅월, 戊癸년 甲寅월에서 시작해 60갑자 순으로 이어진다.

### Cited Findings
- 절기→월지 표(干支纪月): 立春→寅月, 驚蟄→卯, 清明→辰, 立夏→巳, 芒種→午, 小暑→未, 立秋→申, 白露→酉, 寒露→戌, 立冬→亥, 大雪→子, 小寒→丑; 寅月은 "立春至驚蟄前一日" — [zh.wikipedia 干支](https://zh.wikipedia.org/wiki/干支)
- 오호둔 가결: "甲己之年丙作初，乙庚之歲戊為頭，丙辛歲首從庚起，丁壬壬位順流行，若問戊癸何方法，甲寅之上好推求。" — [zh.wikipedia 干支](https://zh.wikipedia.org/wiki/干支)
- 한국 자료 확인: "甲·己年의 정월은 丙寅이다" — [m.cafe.daum.net/gildosa](https://m.cafe.daum.net/gildosa/D5Zt/126); "한 해 정월(寅월)의 천간은 그 해 천간으로 정해지고(오호둔, 五虎遁), 그다음 달부터는 60갑자 순서로 이어집니다", 2017년 정월 壬寅, 2000년 정월 戊寅 — [datedb.net 월건](https://datedb.net/calendar/wolgeon/2017/), [datedb.net 2000](https://datedb.net/calendar/wolgeon/2000/)
- 天气网 2000-01-01 "己卯年 丙子月": 己년 → 丙寅월 시작, 子월(11번째) = 丙子 — 표와 일치 — [wannianli.tianqi.com](https://wannianli.tianqi.com/laohuangli/2000nachu.html)

**구현용 표**

- 월간 공식 (천간 甲=0…癸=9): `mg = ((yg mod 5) × 2 + 2 + k) mod 10` → 甲/己(0,5)→丙(2), 乙/庚→戊(4), 丙/辛→庚(6), 丁/壬→壬(8), 戊/癸→甲(0). 월지 = `(2 + k) mod 12` (寅=2). (가결을 수식화; 검증 실행에서 1992-10-24 → 庚戌월, 2000-01-01 → 丙子월로 출처값과 일치.)

### Inferences
- 사주 연도 `sajuYear`의 12절 절입 순간 배열(입춘…대설은 sajuYear, 소한은 sajuYear+1의 1월)을 만들고, 출생 시각 이상인 마지막 절의 k를 월지 index로 쓰면 됨. 소한(丑월)은 "익년 1월"에 속하지만 사주 연도는 아직 전년임(입춘 전).

## Q4. 절기(12절) 절입 시각 계산: Meeus 태양 황경법 vs C값(寿星) 공식

### Takeaway
Meeus 『Astronomical Algorithms』 25장의 저정밀 태양 황경식(평균황경 L0, 평균근점이각 M, 중심차 C, 시황경 λ = L0 + C − 0.00569° − 0.00478°·sin Ω)에 뉴턴 반복을 적용하면 1900~2100 전 구간에서 외부 라이브러리 없이 절입 시각을 구할 수 있고, KASI 기반 공표값과 비교한 오차는 2024·2025년 24개 절 모두 **8분 이내**였다(이론 최대 ≈15분). C값 공식은 북경시(UTC+8) 기준 "날짜"만 주는 근사식으로, 절입이 KST 00:00~01:40 사이인 해(1901~2100 중 약 4%)에 KST 날짜가 하루 틀리므로 한국용으로는 부적합.

### Cited Findings

**(a) Meeus 저정밀 태양 황경 (권장)**
- T = (JDE − 2451545.0)/36525 (율리우스 세기, 지구역학시 TT 기준) ; L0 = 280.46646 + 36000.76983·T + 0.0003032·T² ; M = 357.52911 + 35999.05029·T − 0.0001537·T² — [arXiv 2604.01233 (Meeus 상수 인용)](https://arxiv.org/pdf/2604.01233); [pymeeus Sun 소스](https://pymeeus.readthedocs.io/en/stable/_modules/pymeeus/Sun.html)
- 중심차: C = (1.914602 − 0.004817·T − 0.000014·T²)·sin M + (0.019993 − 0.000101·T)·sin 2M + 0.000289·sin 3M ; 진황경 ☉ = L0 + C — [pymeeus Sun 소스](https://pymeeus.readthedocs.io/en/stable/_modules/pymeeus/Sun.html); [Frink sun.frink (Meeus ch.25 구현)](https://futureboy.us/frinksamp/sun.frink)
- 시황경(저정밀 장동·광행차 보정): Ω = 125.04 − 1934.136·T ; λ = ☉ − 0.00569° − 0.00478°·sin Ω — [Frink sun.frink](https://futureboy.us/frinksamp/sun.frink)

## Q5. 시주(時柱): 12시진, 오서둔(시두법), 30분 보정, 표준시·서머타임 이력

### Takeaway
시지는 2시간 블록(子 23~01, 丑 01~03, …), 시간은 오서둔(五鼠遁): 甲己일 甲子시, 乙庚일 丙子시, 丙辛일 戊子시, 丁壬일 庚子시, 戊癸일 壬子시. 한국은 표준자오선 135°E(KST)인데 국토 중심은 127.5°E라 명리 실무에서 약 30분(서울 −32분)을 빼는 것이 "가장 보편적"이며, 1908-04-01~1911-12-31과 1954-03-21~1961-08-10은 표준시가 UTC+8:30이어서 30분 보정을 하지 않고, 서머타임(1948~51, 1955~60, 1987~88) 기간은 1시간을 뺀다.

### Cited Findings

**12시진·오서둔**
- 干支紀時 표(UTC+8 기준): 子 23:00–01:00, 丑 01–03, 寅 03–05, 卯 05–07, 辰 07–09, 巳 09–11, 午 11–13, 未 13–15, 申 15–17, 酉 17–19, 戌 19–21, 亥 21–23 — [zh.wikipedia 干支](https://zh.wikipedia.org/wiki/干支); 나무위키 자시: "오후 11시에서 다음 날 오전 1시에 해당한다", 해시 "오후 9시에서 오후 11시" — [namu.wiki 자시](https://namu.wiki/w/자시)
- 오서둔 가결: "甲己还加甲，乙庚丙作初；丙辛从戊起，丁壬庚子居；戊癸何方发，壬子是真途。" — [zh.wikipedia 干支](https://zh.wikipedia.org/wiki/干支)
- 구현 공식(검증 실행): 시지 index `hz = ⌊((hour+1) mod 24)/2⌋` (23시→0 子), 시간 `hg = ((일간 mod 5)×2 + hz) mod 10` → 甲/己→甲(0), 乙/庚→丙(2), 丙/辛→戊(4), 丁/壬→庚(6), 戊/癸→壬(8). manseryeok 예제 1992-10-24 05:30(계일, 묘시) → 을묘시 재현.

### Inferences
- 구현 절차(시계 시각 → 계산용 시각):
  1. 서머타임 구간이면 −60분 (1955~60은 기준이 UTC+8:30이므로 서머타임 시계 = UTC+9:30 → 오늘의 KST로는 **+30분**, 진태양시로는 −30분 추가 → 합계 −60분과 동일).
  2. 표준시가 UTC+8:30이던 구간(1908-04-01~1911-12-31, 1954-03-21~1961-08-10)은 시계가 이미 127.5°E 기준 → 30분 보정 생략; 단 **절입 시각(KST)과 비교할 때는 +30분**해서 KST로 환산(연주·월주 판정용). 1900-01-01~1908-03-31은 LMT 8:27:52(서울)로 사실상 127°E 지방시 → 같은 취급(KST 환산 +32분).
  3. 그 외 구간은 KST 그대로 절입과 비교하고, 시주 판정용 시각만 −30분(또는 경도 기반 (λ−135)×4분, 서울 −32분).
- "주류 관행" 요약: 상용 앱(포스텔러)은 동경시/서머타임 자동 보정 + 야자시/조자시 선택형; 오픈소스(manseryeok)는 보정 기본 OFF; 실무는 "−30분이 가장 보편적"(논문). 따라서 제품 기본값은 "−30분 적용, 일주 경계 자정, 야자시 OFF"가 무난하고, 옵션으로 토글 제공.

### Gaps
- 포스텔러·점신의 **기본값**(30분 보정 ON/OFF, 균시차 적용 여부)은 공식 문서 미확인.
- 1955~1960 서머타임 1시간이 UTC+8:30 기준 +1h(=UTC+9:30)였다는 점은 영문 위키의 "UTC+9:30"으로만 확인(IANA 규칙상 base 8:30 + 1:00과 일치).

## Q6. 검증 예제 (출생 일시 → 네 기둥)

### Takeaway
아래 6개 예제 중 1~3번은 외부 출처값(manseryeok README, 天气网 老黄历)과 네 기둥/세 기둥이 일치하고, 4~6번은 동일 구현으로 계산한 경계 사례(출처 교차검증은 부분적).

### Cited Findings
1. **1992-10-24 05:30 KST (보정 없음)** → 壬申년 庚戌월 癸酉일 乙卯시. 출처값 "임신연주, 경술월주, 계유일주, 을묘시주" — [github.com/yhj1024/manseryeok](https://github.com/yhj1024/manseryeok); 검증 실행 동일.
   - 풀이: 1992 → (1992−4) mod 10 = 8 壬, mod 12 = 8 申. 한로(10/8) 이후·입동(11/7) 이전 → 戌월(k=8); 壬년 → 壬寅 시작 → 寅壬 卯癸 辰甲 巳乙 午丙 未丁 申戊 酉己 戌庚 → 庚戌. JDN 2448920+49 = 2448969 mod 60 = 9 → 癸酉. 05:30 → 卯(hz=3); 癸일 → 壬子 시작 → 子壬 丑癸 寅甲 卯乙 → 乙卯.
2. **2000-01-01 12:00 KST** → 己卯년 丙子월 戊午일 戊午시. 출처값 "己卯年 丙子月 戊午日" — [wannianli.tianqi.com](https://wannianli.tianqi.com/laohuangli/2000nachu.html); 검증 실행 동일(시주는 계산값: 戊일 → 壬子 시작, 午(hz=6) → 壬+6 = 戊 → 戊午).
3. **2024-03-10 23:30 KST** → 甲辰년 丁卯월 + (자정 기준) 癸酉일 壬子시 / (야자시 'jasi') 甲戌일 甲子시 / ('splitJasi') 癸酉일 甲子시. 출처값: "midnight: 계유일 임자시 / jasi: 갑술일 갑자시 / splitJasi: 계유일 갑자시" — [github.com/yhj1024/manseryeok](https://github.com/yhj1024/manseryeok); 검증 실행 동일.
4. **2025-02-03 22:30 vs 23:30 KST (입춘 2025-02-03 23:10 KST)** → 22:30: 甲辰년 丁丑월 癸卯일 癸亥시 ; 23:30: 乙巳년 戊寅월 癸卯일 壬子시. 입춘 시각 출처 — [month2k 2025](https://month2k.com/dates/division24/2025), [dallyeok](https://dallyeok.com/solarterms/ipchun/); 네 기둥은 검증 실행(계산값).
5. **1987-07-15 10:00 (서머타임 시계) → 09:00 KST** → 丁卯년 丁未월 乙丑일 辛巳시 (검증 실행). 서머타임 구간 1987-05-10 02:00~10-11 03:00 — [IANA tz](https://raw.githubusercontent.com/eggert/tz/main/asia). 년·월(丁卯/丁未)은 天气網 1987년 7월 표와 일치(소서 이후 丁未月) — [wannianli.tianqi.com 1987-07](https://wannianli.tianqi.com/laohuangli/198707ruzhai.html); 일주는 Gaps 참조.
6. **1900-01-31 12:00** → 己亥년 丁丑월 甲辰일 庚午시 (검증 실행; 입춘 1900-02-04 14:55 KST 계산값 이전이므로 1899 己亥년·丑월). 일주 甲辰은 과제에 주어진 기지값과 일치.

### Inferences
- 예제 1~3이 독립 출처와 완전히 일치하므로 (JDN+49) 일주식, 오호둔·오서둔 수식, 입춘/절입 경계 로직이 함께 검증된 것으로 볼 수 있음.
- 예제 4는 절입 10분 차로 연주·월주가 모두 바뀌는 사례로, UI에서 "절입 ±15분 경계" 경고의 근거.

### Gaps
- 예제 5의 일주(乙丑): 天气網 1987년 7월 월력표는 7/15를 癸丑으로 표기하지만 같은 페이지 하단 박스(7/13 癸亥)와 12일 어긋나는 자체 모순이 있어 신뢰 불가. 2000년 앵커(戊午)에서 4748일 역산(4748 mod 60 = 8)하면 1987-01-01 = 庚戌, 7/15 = 乙丑으로 공식과 일치하나, 1987년에 대한 독립 외부 확인은 얻지 못함.
- 유명인의 공개 사주 등 "제3의 완전한 네 기둥 공표 사례"는 확보하지 못함(검색 결과 없음).

## 부록: 참조 구현 (검증 실행에 사용한 JavaScript, 외부 라이브러리 없음)

```js
// --- 60갑자 ---
const GAN="갑을병정무기경신임계", JI="자축인묘진사오미신유술해";
// --- JDN (그레고리력, 정오 기준 정수) ---
function jdn(y,m,d){const a=Math.floor((14-m)/12),yy=y+4800-a,mm=m+12*a-3;
  return d+Math.floor((153*mm+2)/5)+365*yy+Math.floor(yy/4)-Math.floor(yy/100)+Math.floor(yy/400)-32045;}
// --- JD(실수, UT 0h = .5) ---
function jd(y,m,d,h){if(m<=2){y-=1;m+=12;}const A=Math.floor(y/100),B=2-A+Math.floor(A/4);
  return Math.floor(365.25*(y+4716))+Math.floor(30.6001*(m+1))+d+B-1524.5+h/24;}
// --- Meeus ch.25 저정밀 시황경(도) ---
const R=Math.PI/180;
function sunLon(jde){const T=(jde-2451545)/36525;
  const L0=280.46646+36000.76983*T+0.0003032*T*T;
  const M=(357.52911+35999.05029*T-0.0001537*T*T)*R;
  const C=(1.914602-0.004817*T-0.000014*T*T)*Math.sin(M)+(0.019993-0.000101*T)*Math.sin(2*M)+0.000289*Math.sin(3*M);
  const Om=(125.04-1934.136*T)*R;
  return (((L0+C-0.00569-0.00478*Math.sin(Om))%360)+360)%360;}
// --- ΔT(초) : NASA/Espenak-Meeus 다항식 (1900~2150) ---
function deltaT(y){let t;
  if(y<1920){t=y-1900;return -2.79+1.494119*t-0.0598939*t*t+0.0061966*t**3-0.000197*t**4;}
  if(y<1941){t=y-1920;return 21.20+0.84493*t-0.0761*t*t+0.0020936*t**3;}
  if(y<1961){t=y-1950;return 29.07+0.407*t-t*t/233+t**3/2547;}
  if(y<1986){t=y-1975;return 45.45+1.067*t-t*t/260-t**3/718;}
  if(y<2005){t=y-2000;return 63.86+0.3345*t-0.060374*t*t+0.0017275*t**3+0.000651814*t**4+0.00002373599*t**5;}
  if(y<2050){t=y-2000;return 62.92+0.32217*t+0.005589*t*t;}
  return -20+32*((y-1820)/100)**2-0.5628*(2150-y);}
// --- k번째 절(0=입춘 … 11=소한)의 절입 JD, KST 달력(= UT JD + 9/24) ---
function jeolKST(sajuYear,k){const target=(315+30*k)%360, gy=k<11?sajuYear:sajuYear+1;
  let x=jd(gy,1,1,0)+(k<11?34+30.44*k:4);
  for(let i=0;i<30;i++){let df=sunLon(x)-target;df=((df+180)%360+360)%360-180;
    const step=df/0.98564736;x-=step;if(Math.abs(step)<1e-7)break;}
  return x-deltaT(gy)/86400+9/24;}
// --- 네 기둥. (y,m,d,hh,mi)는 서머타임 제거 후 KST 시계 시각. solarMin: 시주용 경도 보정(예 -30) ---
function fourPillars(y,m,d,hh,mi,{dayBoundary='midnight',solarMin=0}={}){
  const t=jd(y,m,d,hh+mi/60);                       // KST 달력 JD
  let Y=y; if(t<jeolKST(y,0)) Y=y-1;                // 입춘 전이면 전년
  const yg=((Y-4)%10+10)%10, yz=((Y-4)%12+12)%12;
  let k=0; for(let i=0;i<12;i++) if(t>=jeolKST(Y,i)) k=i;
  const mz=(2+k)%12, mg=((yg%5)*2+2+k)%10;
  // 시주용 시각(경도 보정)
  let tm=hh*60+mi+solarMin, dayJ=jdn(y,m,d), hourBaseJ;
  if(tm<0){tm+=1440;dayJ-=1;} else if(tm>=1440){tm-=1440;dayJ+=1;}
  hourBaseJ=dayJ; const H=Math.floor(tm/60);
  if(H>=23){ if(dayBoundary==='jasi'){dayJ++;hourBaseJ++;} else if(dayBoundary==='splitJasi'){hourBaseJ++;} }
  const di=((dayJ+49)%60+60)%60, dg=di%10, dz=di%12;
  const hz=Math.floor(((H+1)%24)/2), hbg=(((hourBaseJ+49)%60+60)%60)%10, hg=((hbg%5)*2+hz)%10;
  return [GAN[yg]+JI[yz], GAN[mg]+JI[mz], GAN[dg]+JI[dz], GAN[hg]+JI[hz]];
}
// 예: fourPillars(1992,10,24,5,30) → ["임신","경술","계유","을묘"]
```

주의: 위 코드의 `solarMin`을 적용하면 일주 날짜도 보정된 시각으로 결정되는데(예: 00:10 출생에 −30분 → 전날), 이는 "진태양시 기준 일주"를 택하는 방식이다. 주류 관행대로 "일주는 시계 자정, 시주만 보정"으로 하려면 `dayJ`를 보정 전 날짜로 고정하면 된다(출처: Q1·Q5 Cited Findings의 관행 설명; 어느 쪽이 다수인지는 Gaps 참조).
