# 삼합궁합

혈액형 · MBTI · 사주(생년월일시)를 하나로 합쳐 방 안 친구들과의 궁합 순위를 매기는 웹앱.
배포: https://samhap.vocaday.workers.dev

## 쓰는 법
1. 홈에서 방 이름·인원수를 넣고 방을 연다 → `#/r/{방ID}` 링크가 생긴다.
2. 링크를 단톡방에 공유한다. 들어온 사람마다 이름·혈액형·MBTI·생년월일(·생시)을 넣는다.
3. 궁합 순위(나 기준, 항목 펼치면 이유), 유대 지도(방 전체 별자리), 내 사주(네 기둥·오행)를 본다.
4. 내 정보는 입력한 브라우저에서만 수정·삭제할 수 있다(토큰이 localStorage에 저장됨).

## 점수
`총점 = 혈액형 25% + MBTI 35% + 사주 40%` (0~100).
- 혈액형: 한국에 널리 퍼진 궁합표를 양방향 평균한 대칭표(친구 모드: 같은 혈액형 +5).
- MBTI: 한국에서 가장 많이 공유되는 16×16 궁합표를 양방향 평균(95/80/70/60/50/40).
- 사주: 50점 기준에 일간 합·충·십신, 일지·월지·년지(띠)·시지의 합·충·형·파·해·원진·귀문, 교차 합충, 오행 보완·간이 용신을 가감.
  일주 > 월지 > 년지 > 시지 순으로 가중.
근거와 출처: `research_notes/`, 종합 보고서 `reports/`.

## 만세력
`public/lib/saju.js` — 라이브러리 없이 계산.
- 년·월 경계: 태양 황경(Meeus 저정밀 공식, 오차 ≈15분)으로 입춘·절기 판정.
- 일주: 율리우스일 `(JDN + 49) mod 60`. 날짜 경계는 시계 자정.
- 시주: 진태양시(표준시 −30분, 동경 127.5° 기준). 1908~1911·1954~1961년 UTC+8:30, 서머타임(1948~51·1955~60·1987~88) 자동 보정.
- 음력 생일 입력은 미지원(양력만).

## 개발
```
npm test              # 규칙표·만세력 검증 (node --test)
npx wrangler dev      # 로컬 (D1 로컬 스키마: wrangler d1 execute samhap --local --file schema.sql)
npx wrangler deploy   # 배포
```
구조: `src/worker.js`(API 5개 + 정적 자산), `public/`(화면, 계산은 전부 브라우저), D1 `rooms(id, data JSON, updated_at)`.
