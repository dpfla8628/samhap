# 삼합궁합 — 혈액형·MBTI·사주 총집합 궁합방 설계 (2026-10-13)

## 사용자가 말한 것 (요구)
- 혈액형 + MBTI + 생년월일시 를 입력하면 사주(특히 일주)까지 분석해 세 체계를 **합친** 궁합 점수를 낸다.
- 단톡방 인원수를 정해 방을 만들고, 링크를 공유해 친구들이 각자 정보를 넣으면 **나 기준 친구별 궁합 랭킹**이 인터랙티브하게 보인다.
- 방 안 사람들끼리의 궁합 유대(네트워크)를 볼 수 있다. (친구의 친구까지 무한 확장은 100명 넘으면 버벅일 것 같아 **방 단위로 한정**하기로 사용자가 스스로 결정.)
- 화면은 직관적·사용자 편의 우선, 디자인은 점술·역술·운세·무속·유사과학 느낌.
- 배포해서 여러 사람이 접속 가능해야 함.

## 내가 가정한 것 (확인 없이 진행 — "자동 yes" 규칙)
- 로그인 없음. 방 링크를 아는 사람은 누구나 입력·열람. 자기 항목 수정·삭제는 입력 시 받은 토큰(브라우저에 저장)으로만.
- 궁합 종류는 "친구/일반 궁합"(연애 전용 아님).
- 생시는 선택 입력. 모르면 시주 없이 삼주로 계산하고 점수에 그 사실을 표시.
- 음력 생일 입력은 1차에서 제외(ponytail: 양력만). 필요하면 음양력 변환표 추가.
- 점수는 혈액형 25% · MBTI 35% · 사주 40% 가중 평균(사주가 정보량이 가장 많음). 리서치 결과에 따라 조정.
- 서비스명: **삼합궁합** (三合 = 세 체계의 합 + 사주 용어 삼합 + 홍어삼합 말장난).

## 접근 선택
1. (선택) Cloudflare Worker + 정적 자산 + D1 한 테이블(rooms: id, json). 계산은 전부 브라우저 JS. vocaday와 같은 계정·같은 패턴이라 배포가 한 줄. 서버는 저장만.
2. 서버에서 계산 + 캐시 — 불필요. 방 인원 ≤ 50이면 브라우저가 수백 쌍을 ms 단위로 계산.
3. Firebase/Supabase 실시간 — 새 의존성·계정. 불필요.

## 구조
- `public/index.html` 단일 페이지(해시 라우팅: `#/` 홈, `#/r/{roomId}` 방).
- `public/lib/saju.js` 만세력: 생년월일시 → 년·월·일·시주(절기·KST 보정). 순수 함수, Node 테스트 가능.
- `public/lib/rules.js` 데이터표: 혈액형 4×4, MBTI 16×16, 간지 합·충·형·파·해·원진.
- `public/lib/score.js` 두 사람 → {total, blood, mbti, saju, reasons[]}.
- `public/app.js` UI, `public/style.css`.
- `src/worker.js` API 5개 + 정적 자산.
- `test/*.mjs` node assert 검증(알려진 날짜의 일주, 점수 대칭성, 범위).

## 데이터
```
rooms(id TEXT PRIMARY KEY, data TEXT, updated_at INTEGER)
data = { name, size, createdAt, members:[{ id, name, blood, mbti, birth:'YYYY-MM-DD', time:'HH:MM'|null, token }] }
```
GET 응답에서 token 제거. 수정/삭제는 token 일치 시만.

## API
- `POST /api/rooms` {name,size} → {id}
- `GET /api/rooms/:id` → room(토큰 제외)
- `POST /api/rooms/:id/members` {name,blood,mbti,birth,time} → {memberId, token}
- `PUT /api/rooms/:id/members/:mid` {token,...필드} → room
- `DELETE /api/rooms/:id/members/:mid` {token} → room
입력 검증: 이름 1~12자, blood ∈ {A,B,O,AB}, mbti 정규식, birth 1900~2100, time HH:MM, 방 인원 2~60.

## 화면
1. 홈: 서비스 소개 한 줄 + "방 만들기"(방 이름, 인원수). 만들면 바로 방으로 이동 + 링크 복사/공유.
2. 방 — 내 정보 입력(처음 한 번): 이름 / 혈액형 4타일 / MBTI 글자쌍 토글 4개 / 생년월일(date) / 생시(time, "모름" 체크).
3. 방 — 결과: 상단에 내 사주 카드(일주 설명). "나와의 궁합 랭킹" 리스트(점수·등급·한 줄 이유), 항목 펼치면 혈액형/MBTI/사주 세부와 이유 목록. "유대 지도" 탭: 방 전체 네트워크(캔버스, 선 굵기·색 = 점수). 입력 진행도 "3/8명".
4. 자기 정보 수정·삭제.
